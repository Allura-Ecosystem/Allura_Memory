# Security Policy

This repository follows the
[Allura Security Policy](https://github.com/Allura-Ecosystem/.github/blob/main/SECURITY.md).

## Reporting

Do not report vulnerabilities, credentials, customer records, or private
client details in a public issue.

Use GitHub private vulnerability reporting for this repository:
<https://github.com/Allura-Ecosystem/Allura_Memory/security>

If private reporting is unavailable, contact the repository owner privately
through the verified organization account.

## Claims

Security language must be tied to current implementation evidence. Terms such
as `secure`, `private by design`, or compliance language are not certifications
unless a current audit proves them.

## Completion

A fix is complete only after the relevant validation and release evidence are
recorded (see [`docs/portfolio/evidence-index.md`](docs/portfolio/evidence-index.md)).
