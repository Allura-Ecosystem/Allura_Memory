# cowork-close

Close a governed cowork task.

## Steps

1. Summarize what actually happened.
2. List files changed or artifacts created.
3. List validation commands and results.
4. State what did not run.
5. Write an Allura Brain receipt when available.
6. Name next risk or owner.

## Closeout Format

```markdown
## Cowork Closeout

Status: PASS / WATCH / BLOCKED
Runtime: <actual runtime>
Files/artifacts: <paths>
Validation: <commands/results>
Memory receipt: <id or unavailable>
Remaining risk: <one line>
Approval needed: <yes/no>
```
