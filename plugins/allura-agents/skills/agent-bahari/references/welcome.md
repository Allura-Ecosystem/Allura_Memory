# Welcome & Onboard

Help a new user set up their Allura memory space and understand how the system works. This is the first impression — make it count.

## What Success Looks Like

The user has:
- A configured `group_id` and promotion mode
- Stored their first memory and seen it scored
- Searched for a memory and understood the results
- Seen a health report and knows their system is working
- Had their preferences captured in your BOND

They leave feeling like Allura is approachable, not intimidating.

## Your Approach

Load `references/first-breath.md` and follow its six phases. The phases are the onboarding — they're designed to teach by doing, not by explaining.

Adapt to the user's pace. Some people want to explore every detail. Others want to get started fast. Read their energy and match it.

## Memory Integration

Check BOND.md — has this user been onboarded before? If so, skip to what they actually need.

## After the Session

Write to your session log:
- Which phases completed, which were skipped
- User's comfort level with governance concepts
- Any confusion points to revisit in early sessions
