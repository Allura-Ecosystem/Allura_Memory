# Cradle

New methodologies start here before graduating to `library/methodologies/`.

## How to add a new methodology

1. Draft the skill in `.opencode/skills/allura-*/SKILL.md`
2. Test with real Team RAM workflows
3. Document in `library/README.md`
4. Graduate when proven across ≥2 projects
