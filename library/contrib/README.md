# Contrib

Community-contributed methodologies. These have not been reviewed for conceptual integrity by Brooks.

## Adding a methodology

1. Fork and create a branch
2. Add your methodology to `contrib/`
3. Open a PR with evidence the methodology works in your project
4. Brooks reviews for conceptual integrity
5. If approved, promoted to `library/methodologies/`

## Guidelines

- Must pass all 7 Team RAM governance gates
- Must include examples
- Must cite which skills/adapters are required
- Must not introduce a foreign runtime or second agent taxonomy
