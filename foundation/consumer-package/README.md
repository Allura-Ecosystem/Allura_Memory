Pack receipt records exact source HEAD/input SHA256 and tarball SHA256; a HEAD without dirty-input digests is insufficient evidence. Runtime pins: Bun1.3.14, Node24.19.0; official MCP SDK1.32.2. ## Storage and first use

All SDK/CLI/stdio writes use authenticated MCP memory_add at your explicitly configured /mcp endpoint. There is NO generic REST capture route. PostgreSQL stores append-only evidence/replay/receipts; capture is not semantic approval, scoring, or a generated proposal. Independent authorized human promotion remains required. Indexing is separately observable. External projection is not configured. Get/list default to current semantic versions; `get({kind:'receipt',id:receipt_id})` reads your exact capture receipt. These identifiers are not interchangeable. Search `status:'all'` explicitly includes eligible unapproved evidence, never other workspaces. Threshold is only an accepted future proposal-selection hint, never approval.

SDK: import {AlluraClient} from '@allura/memory-consumer'; construct with endpoint,groupId,workspaceId and an async token callback supplied by your secret manager. await client.connect(), then add/search/get/list/delete, finally close(). Inputs are typed; result data is a versioned record with server contract enforcement. invoke() retains the full MCP content/structured result for exact receipt bytes. No provider credential discovery, DevAuth or database access in this package.

CLI: allura-memory memory_add < request.json (likewise memory_search/get/list/delete). Request example: {"content":"An observed deployment fact","idempotency_key":"capture-unique-stable-key"}. Supply ALLURA_ENDPOINT (HTTPS URL ending /mcp with no query/credentials), ALLURA_GROUP_ID, ALLURA_WORKSPACE_ID, ALLURA_TOKEN through your approved environment/secret-injection mechanism, never command arguments. No default endpoint, production credential lookup or silent localhost fallback. ALLURA_ALLOW_LOOPBACK=1 permits only127.0.0.1/[::1] for an explicitly owned fixture. stdout is result JSON; disclosure/errors go to stderr. --help needs no credentials.

MCP stdio: configure the installed allura-memory-mcp executable with the same environment. It proxies the same five tools through official MCP transport; it cannot approve semantic memory or grant access. No runtime agent configuration is changed by installation. Human approval uses the separately authenticated same-origin server review API, not machine tools.

## Error and migration contract

Never automatically retry writes or generate a new key after an ambiguous response. Timeout/disconnect may mean unknown, not rollback: repeat explicitly with the original key and unchanged payload to reconcile. Soft deletion requires exact expectedHeadRevision, reason, operationKey and current memory:delete; it does not erase history. The accepted database contract restricts workspace_admin (and therefore memory:delete) to humans: SDK/CLI/stdio machine deletion is denied, even if the credential ceiling includes that action. The same five-tool implementation is also exposed at /mcp/human for signed, current human identities with mandatory same-origin mutation protection; only a currently authorized human administrator may delete there. This is not bearer-token impersonation or a grant-policy change. Capture remains machine-only and cannot be performed with a human assertion. Human approval remains a separate review route, never a five-tool capability. Current credentials and grants are reread by the server. Initialize/read require memory:read; capture additionally memory:capture, deletion additionally memory:delete.

Request65,536 bytes/response131,072 bytes; client fetch admission16 shared in-process slots retained through actual settlement, default6s deadline (20ms–10s configurable), no redirect following or automatic reconnect/retry. CLI input60,000 bytes/6s; stdio line65,536 bytes/16 calls. This is cooperative cancellation, not forced native preemption. Server budgets remain independently enforced. Network/transport arbitrary errors are redacted, never echoed as credential-bearing text.

Legacy user_id/include_global/offset/sort contracts are NOT silently supported. This fresh package has explicit workspace binding, mandatory capture keys, signed cursors/max20 list pages and exact deletion revisions. Do not point a legacy consumer at this interface or reconfigure the live public tunnel without a separate compatibility migration. No Neo4j dependency. Packed local tests are not clean hosted initialization, independent human usefulness, production load, browser/interactive graph, backup/recovery or release acceptance.
