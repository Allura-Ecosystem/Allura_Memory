## Intent

**Problem:** Exact approvals ready handoff but no durable continuation survives the original process.

**Approach:** Admit a strict owner resume, then separately claim and atomically finish one PostgreSQL-local handoff linked to the exact preparation, request and approving decision. Fresh processes reconcile the original operation key without repeating preparation or renewing approval.

## Boundaries & Constraints

**Always:** Literal revision4 for new admissions; historical parser1–4. Preserve001–027 and old definitions/receipts. Pin actual contract/coordinator/API/gateway/executor and025–028. Current original humans and bindings/grants authorize every transaction and historical disclosure. Resume receipt/resumed event, internal claim, and completion are separate durable transactions. No autogenerated public key. Force deferred constraints before final lease/approval/run expiry checks. Preserve limits, source, dependencies, containers and STOP.

**Never:** Old approval authorizing new behavior, arbitrary execution, caller authority/state overrides, semantic/work-item mutation, cancellation/inspection API, credentials, network infrastructure, remote MCP, deployment, stage/commit/refs, closure or nested workers.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|---|---|---|---|
| Continuation | Current owner, approved revision4 | Immutable resume receipt and one handoff, terminal succeeded | Separate durable boundaries |
| Recovery | Same committed key after lost response or killed process | Original receipt, reconcile eligible incomplete handoff | No renewed approval or prepare |
| Conflict | Changed envelope, stale revision, cross-command key | No mutation | Conflict |
| Ineligible | Missing/rejected/expired approval, drift, stale fence | No handoff | Conflict or truthful blocked drift |
| Authority | Wrong owner, machine, foreign scope, original participant loss | No protected disclosure/effect | Forbidden/not found |
| Historical | Genuine1–3 receipts; old3 approved run | Exact history only; owner old ready/handoff becomes blocked drift | Other unsupported old resumes unchanged |
| Fault | Deferred failure, terminated backend, uncertain acknowledgement | Atomic rollback or authoritative reconciliation | Unknown is not absence |
