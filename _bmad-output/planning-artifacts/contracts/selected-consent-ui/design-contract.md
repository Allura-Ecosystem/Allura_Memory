## Exact local technical contract
1. Only /dashboard/oauth/selected-consent?transaction=… is the selected page. Parse exactly one 43-character base64url transaction; reject extra fields, duplicates, wrong path or fragment. Initial page is neutral; no automatic API request or private details.
2. Labelled namespace and workspace UUID entry are routing hints. Explicit Review connection request calls GET /api/oauth/selected-consent once with transaction, group_id and workspace_id. Existing tenant:member admission and SQL current-share checks perform verification and atomically freeze display. Do not call dashboard context or add enumeration/eligibility APIs.
3. State transitions are entry → displaying → displayed → deciding → closed. Lock synchronously, including duplicate calls. Validate exactly ten display fields: clientId, name, redirectUri, actions, groupId, workspaceId, transaction, nonce, mode, connectionId. Require exact requested scope/transaction, bounded nonempty app/name, canonical callback, mode=selected, actions=[memory:selected:read], 43-character nonce and lowercase v4 connection UUID. Freeze object/actions; never render nonce/transaction.
4. Explicit approve uses retained Confirm. Dismissal is a no-op. Cancel connection sends decision=cancel. POST contains the frozen ten fields plus decision, not current form values. Both decisions must return exactly {redirect,connectionId}; connectionId must match display. Current eligibility is rechecked for either decision, so share loss can deny cancellation without a callback. Do not fabricate access_denied.
5. Dedicated transport: same-origin credentials, cache:no-store, redirect:error, JSON-only status200, bounded streamed response (existing 16384-byte ceiling), finite timeout (existing 5000ms default) and abort-race handling even when fetch ignores abort. No bearer input, storage, telemetry, dashboard authority, enumeration or browser token exchange.
6. Callback must be canonical HTTPS or supported HTTP loopback, without userinfo/fragment, exact displayed origin/path and unchanged registered query fields. Reject duplicate/unexpected protocol parameters. Approval has exactly one valid code and no error; cancellation has access_denied and no code. Preserve the returned callback verbatim. Display does not expose original OAuth state: browser validates shape only; the requesting client/callback witness compares original state exactly before SDK finishAuth. Do not invent a browser-side state comparison or enlarge the backend DTO.
7. Close/abort and discard late responses on failure, unmount, pagehide, popstate, actual reload/back-forward and persisted restoration. Any denied/stale/expired/malformed/interrupted/unknown result clears private state and requires fresh client authorization. Never retry, redisplay, remint automatically or infer rollback. A lost successful approval response can leave a pending connection, but no credential exists before exchange.
8. Consent freezes a connection request, not a new content-share snapshot. Existing current per-version sharing remains authoritative at every read. No additional grant/share/owner connection is created; selected remains selected-only after recipient elevation.

## Risks, unknowns and quality gate
Real account sign-in, installed Gilliam/Hermes/ChatGPT/Claude, hosted TLS/registration, live recipient witnesses and authorized human visual/accessibility/assistive-technology acceptance remain unperformed external gates (6.5/9.4 stay open). Synthetic signed sessions are explicitly local fixtures. No new screenshot evaluation was performed during design adoption. Known manual scope entry is deliberately not an inventory picker.

P0 design handoff: nine-section DESIGN.md, this evidence/keep-change record, one coherent stance, explicit inferred choices, concrete anti-patterns and concise implementation-handoff.md are required. Functional gate requires every M-row mapped to named executed tests, real SDK/browser/DB receipts, canonical registries, zero missing/skipped cases, parent final-byte verification, preservation/secret/diff checks and owned-fixture cleanup. A screenshot alone is not security evidence; passing local tests are not independent human acceptance.
