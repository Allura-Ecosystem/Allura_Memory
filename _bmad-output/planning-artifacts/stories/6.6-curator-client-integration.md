# Story 6.6 — connect the curator, not just a memory reader

## User outcome and sources

An authorized agent can begin, inspect and resume the supported frozen review in the verified space, retrieve full linked evidence and hand off one exact batch to the genuine independent human surface. A human-only action is never advertised as an agent capability. Sources: [approved Correct Course](../sprint-change-proposal-2026-11-05-bahari.md), [curator contract](../contracts/curator-batch-v1.md), BAH-R01/R03/R04/R07, FR-D1/D5/F1, NFR-1/3/4/7/8. Accepted 6.2 SDK/CLI/MCP evidence and all deployed-client compatibility gaps are preserved.

## Dependency and scope

4.5 must establish actual versioned backend DTOs/operations before adapter implementation. Read-only client inventory and protocol contract preparation may happen earlier without claiming this story complete. Reuse packed consumer/runtime/contract tooling and genuine human handoff; no universal MCP-to-human conversion. Add an explicitly versioned curator extension/module. Preserve five core tool semantics and bounded existing protocol behavior; do not simply expose human delete/decision to a machine.

Code map: `foundation/src/{consumer-contract,consumer-client,consumer-mcp,consumer-cli,consumer-runtime,mcp-api,core-api}.ts`, current package scripts, actual SDK declarations, `consumer-*`/protocol/CI/packed-server tests. Exact new extension files/registrations are pinned at admission. Real installed profile/credential/endpoint rollout is separate and requires exact scope; local synthetic package tests cannot mutate a user's connection or claim installed acceptance.

## Acceptance criteria

- **BAH-66-01:** inventory exact backend/client contract versions, configured principal/space, discovered actions and actual callable preparation/readback. Separate declared/discovered/callable/authorized. A tool count, initialize response or healthy gateway alone never marks curator Ready.
- **BAH-66-02:** actual packed SDK/CLI/stdio client can freeze/page/read/seal/reconcile 4.5 sets over authenticated governed transport without source-relative imports or direct DB. Full evidence is distinguishable from preview, semantic ID and capture receipt.
- **BAH-66-03:** preparation uses the original authorized identity/space and existing ceiling. Device/selected-only, absent action, foreign scope, revoked credential and machine human-decision attempts deny without fallback or disclosure.
- **BAH-66-04:** exact reviewed manifest/selection reaches a genuine independent-human same-origin surface. The agent receives only authorized references/readback, never a human credential or an invented approval. Missing supported human handoff is explicitly blocked, not a fake link/button.
- **BAH-66-05:** stale discovery refreshes through an actually supported host mechanism once; otherwise give one supported credential/space-preserving recovery action. Unavailable backend/denied source/policy/conflict/expired authority/unknown commit stay distinct. Reconnecting unchanged unsupported code is not offered as a cure.
- **BAH-66-06:** restart/lost response preserves original scope/set/item operation identities; no regenerated retry key, duplicate decision or lost completed receipt. Honest partial/unknown states flow to callers.
- **BAH-66-07:** real protocol/packed compatibility, negative tests, bounded streams/redaction and current canonical inventories pass. Bind actual installed-client proof separately; preserve legacy versus beta identity and existing clients until authorized rollout.

## First RED, exclusions and done

First RED after 4.5: an actual packed stdio client lists its versioned curator capabilities and freezes/pages/reads one 25-member set; current unextended consumer cannot perform this journey. Pair with machine-decision denial. Do not mock the whole backend contract as proof.

No grant/token/config/service change, permission broadening, scheduler, desktop, source connector, memory migration or semantic policy change. Direct builder self-check and full required current-source lanes apply; no new development-review ceremony. Done means local adapter evidence plus explicitly labeled actual installed-client witness; local packing alone cannot close that witness or 6.5 release acceptance. No status write follows.
