# Story 1.1 — Local executable foundation

Parent: [Epic 1](../epics.md#epic-1--executable-foundation-and-reviewed-build-contracts). Requirement: FR-D3, NFR-7/8. No predecessor.

## Objective and scope

Provide the smallest reproducible local TypeScript package with real behavior tests, independent compiler checking and actual lint. Existing `foundation/` is reused byte-for-byte, not rebuilt or credited as a memory product. It is one private ESM package, no application framework, database, auth, UI, provider or public API. Preserve protected UX, intentional purge and legacy repair STOP.

## Accepted tooling

Bun 1.3.14; Node 24.19.0; TypeScript 5.9.3; ESLint 9.39.1; typescript-eslint 8.46.2; @types/bun 1.3.14; @types/node 24.10.0. Exact manifest and lock reside in `foundation/`. Use declared `bun run install:frozen`, not native install alone, for frozen-install enforcement.

## Acceptance and evidence

1. Only the nine recorded foundation package files supply a dependency-free illustrative text transform: valid text is trimmed and passed once to a callback; invalid input fails before callback; original callback error propagates.
2. Exact runtime pins and present/matching lock are enforced; fresh-cache frozen install and repeat install succeed without lock change. Missing/mismatched pins and lock fail.
3. One real required file executes all three behavior cases with 19 assertions and no skipped required cases; empty discovery, empty file, assertion-free placeholder, skipped case and incorrect behavior fail.
4. Actual `tsc --noEmit` checks maintained source/test/scripts/config independently of transpilation. Deliberate source and test type errors fail, then restored full check passes.
5. Actual ESLint checks the maintained files with enabled rules. Deliberate lint violation fails, then restored full check passes.
6. Dependency fetching is separate from offline checks; no credentials, DB or external services are needed. Network trace and protected-file receipts demonstrate isolation.
7. Separate independent final-byte review verifies actual package hashes and induced-red/restored-green evidence. CI/deployment/product completion is not inferred.

All seven acceptance groups are locally evidenced by the prior foundation receipt, whose package hashes must match before reuse. The reset reruns `PATH=$HOME/.bun/bin:$PATH bun run check` from `foundation/` and verifies all protected bytes. Historical-to-current identity and original raw acceptance/reviews are mapped only in private Operations recovery; no old delivery number is an active dependency.
