2. Exact runtime pins and present/matching lock are enforced; fresh-cache frozen install and repeat install succeed without lock change. Missing/mismatched pins and lock fail.
3. One real required file executes all three behavior cases with 19 assertions and no skipped required cases; empty discovery, empty file, assertion-free placeholder, skipped case and incorrect behavior fail.
4. Actual `tsc --noEmit` checks maintained source/test/scripts/config independently of transpilation. Deliberate source and test type errors fail, then restored full check passes.
5. Actual ESLint checks the maintained files with enabled rules. Deliberate lint violation fails, then restored full check passes.
6. Dependency fetching is separate from offline checks; no credentials, DB or external services are needed. Network trace and protected-file receipts demonstrate isolation.
7. Separate independent final-byte review verifies actual package hashes and induced-red/restored-green evidence. CI/deployment/product completion is not inferred.
