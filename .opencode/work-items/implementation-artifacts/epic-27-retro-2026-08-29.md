## Findings

### F1 — The independent gate caught a real fail-closed hole (accepted, fixed)
`checkPoisoning` blocked only `quarantined`; a `rejected` branch passed all seven checks and could promote — contradicting spike 27.1 §5 and migration 53's frozen-state semantics. Fowler caught it; `checkPoisoning` now blocks `rejected` too. **Lesson:** for security gates, enumerate the frozen statuses explicitly and test each.

### F2 — Enforcement was latent, not active (accepted, fixed)
`evaluateGate` existed with all 7 checks but had zero production callers — `createPromotionProposal` never invoked it. Hightower and Fowler both flagged it. Now wired: the adapter queries `branch_registry`, builds the GateContext, and refuses the INSERT on any failing check. **Lesson:** a gate that isn't wired is a document, not a gate.

### F3 — Multi-row writes were non-atomic (accepted, fixed)
Proposal + transition were two independent statements; a second-insert failure orphaned the first. Wrapped in BEGIN/COMMIT/ROLLBACK per the repo's canonical pattern. **Lesson:** the scoped-transaction pattern is the repo's contract; new modules must follow it.

### F4 — New tenant-scoped tables must register in the inventory (accepted, fixed)
Migration 53's `branch_registry` + `promotion_receipts` were missing from `tenant-table-inventory.ts` — the live-DB CI lane would have failed. Same defect class as the migration-48 tables earlier. **Lesson:** the inventory is a machine-checked gate; register tables at migration time.

### F5 — Retention CHECK was violated by the common quarantine path (accepted, fixed)
`quarantineBranch` wrote non-active statuses with null `retention_expires_at`, violating `chk_branch_registry_retention`. Now fails closed; the runner always supplies a deadline. **Lesson:** unit tests with fake queryables never exercise DB CHECKs — verify against the real schema.

### F6 — Honest upstream verdicts (accepted)
AgenticOW recon: marketing "0.5 ms / 162 B" claims not reproduced (~4.5 ms fork on this hardware; COW loses below ~10k vectors per in-repo bench); 162 B storage and 100% recall reproduced. Verdict: experiment-clear, not adopt-ready; `nativeAnn` rejected as-shipped. AgentDB evaluation: retrieval-feedback pattern won one case but the harness's AgentDB arm was oracle-fed (`expected_ids` as re-rank input) — the reject-AgentDB-as-second-authority decision is robust to that circularity, documented honestly.
