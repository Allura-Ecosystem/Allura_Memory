## Condensed-copy exception

These graphics are approved only when embedded beside their current README explanations and full-size links. Their shorter labels preserve the approved audience, central message, hierarchy, canonical names, and factual boundaries while the surrounding prose carries implementation stages, tenant scope, provenance, runtime-honesty qualifications, and governance caveats.

This approval does not authorize the condensed graphics to:

- replace the full 100–180-word production infographics;
- serve as complete architecture, governance, workflow, or operator documentation;
- imply that a runtime, subagent, handoff, approval, promotion, or deployment executed;
- introduce clients, integrations, versions, counts, metrics, status, or outcomes;
- relax unresolved `[DATA NEEDED]` or public-release gates;
- support universal receipt, instant-promotion, or production-readiness claims.
