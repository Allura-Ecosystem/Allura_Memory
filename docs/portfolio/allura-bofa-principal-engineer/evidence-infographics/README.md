# Allura evidence infographics

These six visuals explain evidence-first engineering patterns in plain language. They make no formal compliance, certification, or external assurance claim.

Each image is an editable SVG plus a presentation-ready PNG. The source strip identifies the repository material behind the pattern shown.

## Plain-language message

Allura helps a team show what happened, who decided, what was tested, and where an answer came from.

## Release boundary

Use the phrase **“Evidence-first engineering patterns.”** Do not use assurance language unless it is supported by a specific, independently verified claim.
