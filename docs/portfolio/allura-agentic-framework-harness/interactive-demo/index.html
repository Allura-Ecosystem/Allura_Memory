Fail-closed boot & health

The control can't be skipped by omission

The gateway refuses to start without authentication; a health gate then proves the stack is live. A missing token cannot silently disable the control.

Why it matters in regulated environments

Fail-closed by construction

The common failure mode — “auth is off when the token env var is unset” — was a real defect here and was removed. Production cannot boot anonymously; the health gate exits non-zero if any check fails.

Policy hook · database-enforced

A cross-tenant write is refused by PostgreSQL

Row-Level Security is enabled and forced, so it applies even to the table owner — the difference between a real control and a decorative one.

Second governed pipeline

Bumblebee — promote, or hold with a reason

Supply-chain threat intelligence, read-only and default-off. It ingests, batches, and either promotes a complete batch or holds a partial one with a stable reason code — nothing reaches exposure without passing the same gate as memory.
