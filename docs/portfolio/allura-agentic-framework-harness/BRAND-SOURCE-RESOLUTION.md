# Brand source resolution

## Decision for this release

This portfolio package uses the production Allura brand gate and its official wordmark as the release authority: Allura Blue `#0D47A1`, Allura Orange `#FF4D1F`, Allura Green `#148A4B`, Allura Ink `#0F1720`, and Allura Cream `#F7F3EE`.

The local `branding-references/DESIGN.md` specifies an alternate palette and Inter. It is recorded as a policy conflict, not blended into the artifacts. The release package therefore uses the production-gate palette, the supplied official wordmark, Noto Sans as the documented Aeonik fallback, and IBM Plex Mono for technical labels.

## Follow-up policy

Brand ownership should reconcile the two sources into one versioned release authority before future external collateral is approved. This package does not overwrite either underlying policy.
