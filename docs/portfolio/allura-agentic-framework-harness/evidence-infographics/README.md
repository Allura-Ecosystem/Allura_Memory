# Portfolio evidence illustrations

For engineering reviewers who want a visual explanation of evidence, access boundaries, human review, history, testing, and sources. These six SVG/PNG pairs support the [portfolio case study](../README.md); they are optional technical material.

For the practical save-and-retrieve task, start with [Getting started](../../../user-guide/getting-started.md) and the [current communication brief](../../../reference/reddit-remediation/brief.md).

## Use this collection

- Inspect the editable [SVG sources](svg/) and corresponding [PNG exports](png/).
- Read the [text descriptions](ALT-TEXT.md) alongside a figure.
- Follow each figure's source reference and verify the relevant implementation and revision before reusing a claim.

These are explanatory patterns, not live system views, proof that every implementation path satisfies the pattern, or formal compliance/certification claims. The historical brand review does not establish newcomer comprehension. Superseded or redundant messages are tracked in the remediation inventory; binaries remain available while incoming references are reconciled.
