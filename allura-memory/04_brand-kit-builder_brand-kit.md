# Section 2: Brand Story

## Origin Narrative

Allura was born from a simple, universal truth: **memories are the foundation of who we are.** In a world drowning in data but starved for meaning, Allura set out to create something different — a memory layer that doesn't just store information, but honors it.

We believe that technology should serve human connection, not replace it. That privacy is not a feature, but a right. That memory should be verifiable, traceable, and yours to control.

Allura combines intelligent design with deep human understanding. We exist at the intersection of memory and AI — not to make machines smarter, but to help people hold on to what matters and share it with the people who matter most.

## Mission Statement

To give people the power to hold on to what matters and share it with the people who matter most.

## Vision Statement

A world where every memory is preserved with clarity, protected with trust, and empowered by intelligence — owned by the people who live it.

| Value | Description | Pillar |

Memory is the foundation. Intelligence is the outcome.

## Usage Rules

| Rule | Specification |
|------|-------------|
| **Clear space** | Minimum distance around the wordmark = X (height of "ll") |
| **Minimum size** | 32px (wordmark) / 24px (lettermark) / 48px (lockup) |

| **Alignment** | Always left-aligned unless centered in a specific composition |

## Typographic Rules

| Rule | Specification |
|------|-------------|
| **Body measure** | Maximum 75 characters per line |
| **Paragraph spacing** | 1.5× the line height (e.g., 16px body = 24px paragraph gap) |
| **Heading margin** | 0.5× the heading size above, 0.25× below |
| **All caps tracking** | Minimum +0.1em for 12–14px; minimum +0.2em for <12px |
| **Underlines** | Never used. Use bold, color, or spacing for emphasis |
| **Italics** | Minimal use. Reserve for editorial or quotes |
| **Numeric formatting** | Use tabular lining numerals for stats (e.g., "10M+") |
| **Hanging punctuation** | Enabled for editorial blocks |

## Web Font Loading

- **Strategy:** Font-display: swap (prevent FOIT, minimize FOUT)
- **Loading order:** Display face → Body face → Icon font (if used)
- **Preload:** Hero headlines should be preloaded if possible
- **Font hosting:** Self-hosted preferred (SOVEREIGN BY DESIGN); CDN acceptable with privacy audit
- **System font fallback:** `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

# Section 6: Brand Voice & Copy Standards

## Voice Definition

| Dimension | Rule |
|-----------|------|
| **Tone** | Warm, thoughtful, empowering — like a trusted librarian who is also a brilliant architect |
| **Language** | Clear and human-first. Avoid jargon and acronyms unless necessary (and then define them) |
| **Perspective** | First-person plural ("We") for brand values; second-person ("You") for user messaging |
| **Perspective Shift:** "We care (because you matter)" |
| **Personality** | Curious, calm, quietly confident. Never arrogant or patronizing. |

## Voice Spectrum

| Attribute | Scale (1–5) | Description |
|-----------|-------------|-------------|
| **Formality** | 3/5 | Professional but approachable. Not casual, not stiff. |
| **Enthusiasm** | 3/5 | Warmly engaged, never hyperbolic. |
| **Complexity** | 2/5 | Simple and clear. Concepts explained without condescension. |
| **Humor** | 2/5 | Subtle warmth, never jokes. Lightness without levity. |

## Must-Not List

| Category | Prohibited Terms / Practices |
|----------|-----------------------------|
| **Clichés** | "Data is the new oil" / "Leverage your data" / "Synergy" / "Optimize your memory" |
| **Dehumanization** | Referring to memory as "data" or "assets" without context. Always prefer "memories" or "stories" when user-facing. |
| **Fear-based urgency** | "Don't lose your memories!" / "Act now before it's too late" / Any FOMO-driven copy |
| **Corporate jargon** | "Synergy," "leverage," "optimize," "bandwidth," "circle back," "boil the ocean" |
| **Overpromising** | "Never forget anything again" / "100% perfect memory" / Unlimited guarantees |
| **Surveillance language** | "Track," "monitor," "capture everything" — except in technical docs with clear user consent context |
| **AI hype** | "Revolutionary AI," "World's first," "Transformative intelligence" — show, don't tell |
| **Negative framing** | Never define Allura by what competitors do wrong. Define by what Allura does right. |
| **Unclear acronyms** | Never use "MCP," "API," "RAG," "LLM" without definition in user-facing copy |

## Headline Standards

| Attribute | Rule |
|-----------|------|
| **Length** | Ideal: 5–8 words. Maximum: 12 words. |
| **Structure** | Active voice. Verb-led where possible. |
| **CTA Style** | Action-oriented, specific, warm. e.g., "Explore your memory graph →" not "Click here" |
| **Capitalization** | Sentence case for headlines ("Memory that shows its work"). Title case for formal overlines. |
| **Punctuation** | Periods on complete sentences. Fragments may skip punctuation for impact. |

## Body Copy Standards

| Attribute | Rule |
|-----------|------|
| **Reading level** | Grade 8–10 (Flesch-Kincaid) for user-facing copy. Grade 12+ for technical docs. |
| **Evidence requirement** | Every claim must be provable or clearly hypothetical (e.g., "We aim to..." not "We guarantee...") |
| **Paragraph length** | Maximum 4–5 sentences. Break up dense information. |
| **Bullet lists** | Preferred for 3+ related items. Never more than 7 bullets. |
| **Numbers** | Spell out "one" through "nine." Use numerals for 10+. Use "10M+" not "10,000,000+" in marketing. |

## Platform-Specific Voice Adjustments

| Platform | Tone Adjustment |
|----------|----------------|
| **Website (Hero)** | Bold, warm, direct. Lead with promise and proof. |
| **Website (Body)** | Conversational, clear, structured. Use whitespace. |
| **Social Media (Instagram)** | Inspiring, visual-first. Pair with imagery. Use hashtags sparingly (#AlluraAI). |
| **Social Media (LinkedIn)** | Thoughtful, industry-aware. Share insights and ideas. |
| **Newsletter** | Warm, informative, conversational. "Updates, insights, and ideas from the Allura team." |
| **Product UI** | Concise, actionable, friendly. Short labels. Clear feedback. |
| **Technical Docs** | Precise, thorough, neutral. Use correct terminology (MCP, vector, BM25, Neo4j). |

## Approved Tagline

> **MEMORY THAT SHOWS ITS WORK**

| Usage | Rule |
|-------|------|
| **Width** | Full width if used independently; never broken across lines |
| **Casing** | Always ALL CAPS |
| **Tracking** | Wide tracking (0.3em+) |
| **Color** | Green `#157A4A` on light backgrounds; white on dark backgrounds |
| **Font** | Medium-weight sans-serif, wide-tracked uppercase |

## Graphic Elements

### Signature Motif
- **Description:** Overlapping blue circle + orange circle + green shape (appears in logos, backgrounds, decorative elements)
- **Usage:** Background embellishments, loading states, section dividers, social media decorative elements
- **Never:** Never scale larger than 50% of the viewport; never rotate more than 15°; never recolor outside approved palette

### Geometric Construction
- **Base shapes:** Circles, rectangles, rounded rectangles (12px border radius), organic overlaps
- **Transparency:** Layered elements use transparency (40–70%) to create depth
- **Rule:** Every geometric element should feel intentional and balanced. Avoid clutter.

### Rounded Corners
- **Containers:** 12px border radius on cards, modals, panels
- **Buttons:** 8px border radius
- **Full pills:** 999px (fully rounded)

# Section 9: Brand in Motion

## Motion Principles

| Principle | Rule |
|-----------|------|
| **Warm Ease** | All motion uses ease curves that feel organic — like memory surfacing, not data loading. |
| **Gradual Reveal** | Content reveals in layers. Background first, then shapes, then text, then CTAs. |
| **Connection Animation** | When showing memory relationships, use flowing lines (not rigid) that suggest organic neural pathways. |
| **Subtle Depth** | Layered shapes move at different speeds (parallax) to create subtle depth without 3D gimmicks. |

## Animation Standards

| Property | Value |
|----------|-------|
| **Easing (default)** | `cubic-bezier(0.25, 0.1, 0.25, 1.0)` — smooth, decelerating |
| **Easing (entrance)** | `cubic-bezier(0.0, 0.0, 0.2, 1)` — fast start, gentle settle |
| **Easing (exit)** | `cubic-bezier(0.4, 0.0, 1.0, 1.0)` — slow start, fast exit |
| **Base duration** | 300–500ms for micro-interactions; 800–1200ms for page transitions |
| **Stagger** | 80–120ms between sequentially revealing elements |
| **Scale on hover** | 1.02–1.05 for subtle lift; never more than 1.1 |

## Video Intro/Outro

| Element | Specification |
|---------|-------------|
| **Duration** | 3–5 seconds |
| **Opening** | Signature motif (overlapping circles) animates in from center, resolving into wordmark |
| **Closing** | Wordmark fades down; tagline appears below; music resolves |
| **Music** | Warm ambient, minimal piano or synth pad. Never aggressive EDM or corporate stock music. |

## Micro-Interactions

| Element | Behavior |
|---------|----------|
| **Buttons** | Scale 1.03 + slight shadow lift on hover; color deepens on active |
| **Links** | Underline animates in from left; color shifts to brand blue |
| **Cards** | Subtle shadow expansion + 1px border color shift on hover |
| **Form inputs** | Border color transitions to brand green on focus; soft inner glow |
| **Loading states** | Signature motif (overlapping circles) animates rotation + pulse |
| **Toggle switches** | Smooth slide with brand blue/green active states |
| **Toasts/notifications** | Slide in from bottom-right; fade after 5s; cream background with charcoal text |

## Social Media Video

- **Instagram Reels:** 15–30 seconds; branded intro; warm ambient music
- **LinkedIn video:** 60 seconds max; direct, informative; no auto-play audio
- **Motion graphics:** Overlapping circles expand and contract like a breathing rhythm — representing memory alive

# Section 10: Governance & Maintenance

## Brand Steward

| Role | Responsibility |
|------|-------------|
| **Chief Brand Officer / Head of Design** | Final approval on all brand changes, new applications, and asset modifications. |
| **Brand Manager** | Day-to-day governance, asset distribution, compliance monitoring. |
| **Visual Director (Glaser)** | Logo, color, typography, photography, motion direction. |
| **Copy Lead (Ogilvy)** | Voice, tone, tagline, messaging. |
| **QA Reviewer (Munari)** | Brand consistency audits, drift detection, compliance enforcement. |

## Change Request Process

1. **Request:** Any stakeholder submits a change request via the Allura Brain event system or project management tool.
2. **Review:** Brand Manager triages the request. Minor changes (e.g., new social template) are fast-tracked. Major changes (e.g., logo modification, color addition) require full review.
3. **Impact Analysis:** Visual Director and Copy Lead assess impact on existing assets and applications.
4. **Approval:** Chief Brand Officer approves or rejects. Decisions are logged in Allura Brain as `DESIGN_DECISION` events.
5. **Implementation:** Approved changes are executed, versioned, and distributed.
6. **Audit:** QA Reviewer verifies implementation against brand kit.
