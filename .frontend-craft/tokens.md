# Allura Token Authority

- Components consume the existing CSS custom properties in `src/app/globals.css`.
- No raw colors are added to TSX.
- No generic shadcn color utilities are used.
- The approved Allura lettermark remains the only logo asset.
- IBM Plex Sans is used for operator copy and IBM Plex Mono for IDs, timestamps, policies, and receipt fields.
- Spacing and radii use the existing Allura scales.
