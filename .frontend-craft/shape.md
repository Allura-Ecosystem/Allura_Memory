# Shape

- Project: Allura Enterprise Modular Dashboard
- Goal: Restore the approved brand-locked curator command center without weakening server-owned scope, evidence, decision, or receipt authority.
- Success: An authenticated reviewer can inspect a real scoped queue, see evidence before actions, record a rationale-bound decision, and inspect the returned immutable receipt in a responsive accessible shell.
- Constraints: Next.js 16 App Router, React 19, Bun only, existing Allura tokens and brand assets, no synthetic production data, no caller-supplied authority, no new authorization plane.
